# Node.js Authentication System 🔐

This project is a user authentication system built using Node.js, Express, and MongoDB. It includes features for user signup, login, and sending email confirmations after successful registration. This project is a part of a personal learning initiative to understand the implementation of authentication and user management in Node.js. 🚀

## Features ✨

- **User Signup**: Register a new user with email, username, and password. 📝
- **User Login**: Secure login using email and password. 🔑
- **Email Confirmation**: After successful signup, a confirmation email is sent to the user. 📧
- **Password Hashing**: User passwords are securely hashed before being stored in the database. 🔒
- **JWT (JSON Web Token)**: Used for securely transmitting user authentication tokens for session management. 🛡️
